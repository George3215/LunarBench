# 初见目标后的遮挡恢复：开源相关工作与对比取舍

核对日期：2026-10-18。以论文、作者项目页与官方仓库为依据；有仓库不等于已在 TASK3 复现。没有将他人不同数据集的成功率与本轮数字并排比较。

本研究的任务是：静态目标起初可见，机器人运动后因地形或建筑结构发生真实遮挡；在没有预建环境图、没有目标真值位置的条件下，利用观测与自身运动恢复目标可见性，最终接近目标。目标从未出现的探索、目标离开视野、动态目标跟踪，与这个问题相关但不完全相同。

## 别人怎样处理“看到后又看不到”

**EZREAL 的方向记忆最接近本题，但公开代码和论文方案必须分开。** 已读取 master 的 `src/tile_node.py`：检测方向先结合当前 yaw 转到固定参考系；目标不可见时读取最近关键帧方向并作角度平均，没有关键帧时用当前朝向。关键帧还保存位置和视觉特征。`src/utils/keyframe_utils.py` 包含基于假设距离、历史位置与当前朝向更新关键帧的逻辑。论文描述的加权融合/主动搜索不能直接等同于当前仓库里已发布的平均方向回退。它提供了很合适的“历史方向保持”机制基线。

**LOVON 的公开数据生成器明确编入丢失后的搜索状态。** `scripts/dataset_generation.py` 中，处于 running 且检测为 NULL 时，按先前搜索状态切到正向或反向旋转搜索；目标重新出现且满足检测条件后再切回接近。训练出的语言到运动模型预测运动、任务状态和搜索状态。它说明短暂丢失恢复已有学习和执行逻辑实现，不能把“增加一个搜索状态”作为新的主要贡献；同时，这种转向恢复不证明能跨越遮挡山脊。

**VLFM 保留由视觉估计得到的空间目标，不因当前一帧缺失就重新从零寻找。** 官方策略的目标点云地图跨帧更新；找到候选目标后选择地图中的目标点，由自身位置/朝向计算 PointNav 输入。因此，遮挡恢复能力部分来自显式空间记忆及低层避障。它是解释“为什么只放历史截图可能不够”的实用参照，而不是无需传感器和控制适配的即插即用模型。

**室内的门、走廊和转角需要把“物体还在那里”和“有路能过去”分开。** 图像记忆方法保留目标/房间证据；在线几何方法维护障碍与可通行连接；语义探索方法在目标未见时选可能房间或前沿。这些机制能跨过局部视线丢失，但通用 ObjectNav 的整体 SR 无法单独证明对真正遮挡的推理，应在统一任务中记录丢失原因、恢复路径及失败反馈。

## 对论文创新定位的影响

以下单独提出不足以支持本研究的新颖性：关键帧记忆、里程计补偿目标方向、目标丢失后旋转搜索、在线二维图、语义前沿探索、给 VLM 加一般推理文字、换一个空间微调检查点。已有工作覆盖了其中多项。

更有价值、仍需实验验证的假设是：**学习一个以自身运动为条件的目标遮挡状态和恢复预测，让它直接参与 VLM 的下一步决策，并用后续观测校正。** 这个描述是研究建议，不是已证明独创性或已完成实现。

- 状态维护：目标相对方位/距离的分布、最后观测证据、当前遮挡/转出视野/不确定的概率；随实际自身运动更新，而非只保存上一段文字。
- 动作预测：对候选动作序列预测指定短时窗内恢复可见的概率、预计行进距离区间和失败风险。未知背面几何允许输出高不确定性，不要求从单帧确定隐面形状。
- 闭环修正：预测与下一次 RGB-D 观测不符时，学习更新状态和重新选择动作；直接评测预测校准及修正是否提高恢复率。
- 训练规模控制：利用仿真新地形/新随机种子自动采集见到→丢失→恢复片段。离线真值只用于标签和评估，不进入推理请求。不用本轮22个测试配置反复训练或挑参。

建议至少包含：同底座未经训练/空间公开检查点/本方法；历史方向保持；旋转重搜；有/无学习状态传递；有/无重现预测；有/无执行反馈修正。若允许在线地图，再加入从相同 RGB-D+里程计构建目标记忆的对照。不能将不同骨干、额外传感器和不同动作执行器混在一次因果消融里。

## 统一复现实验应记录什么

任务分开报告：首次发现（目标从未见过）与重新捕获（之前明确见过）；静态目标与动态跟踪；真实实体遮挡与仅转出视野。首见图像、丢失姿态、场景和目标实例对不同方法保持一致。

恢复可见率、确认到达率、恢复所需动作/路程、错误 STOP、转向震荡/停滞、格式/资源终止分开；学习预测额外报告可见性校准、恢复距离区间覆盖率及未知场景迁移。同一地形族不同强度相关，不能把22配置当22完全独立环境。

表中所有方法均尚未在本次恢复的 TASK3 上完整复现。当前已运行的仍是 Qwen3-VL 与 Spatial-Interactor；新增三模型状态见相邻库存、下载和运行记录。这里没有把公开方法描述转写成我们已获得的实验收益。

当前 TASK3 的统一目标是红球，适合诊断遮挡恢复，但不能单独支撑开放词汇语义理解的泛化结论。论文后续应增加目标外观/类别变化与同类干扰物，保持同一目标实例身份，避免把颜色追踪收益当成通用语义搜索能力。
