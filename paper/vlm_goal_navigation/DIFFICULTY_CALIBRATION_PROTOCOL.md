# Task3 完整评测与有限难度校准

新版要求：目标暂时不可见优先通过浅坡、凹地和坡顶产生；新增障碍统一用固定种子的实体方块，墙体只用于窗口结构。保留全部15类原地形与16个窗口参数变体。平地可增加有记录的低起伏，其他地形优先寻找原有起伏的候选；原 barrier 薄墙在新版中移除并记录。方块的尺寸、位置、种子、XML 和 ablation_id 全部保存。

执行顺序：当前旧墙体版本的186trial完整结束并通过审计 → 完整指标 → 每场景几何难度和本基线经验难度划分 → 保存调整决策 → 构建和物理验证新版31场景 → 新版完整186trial → 必要时最多再调整一个版本并完整评测。最多两个地形版本调整；每trial仍累计1000→2000→3000步，不在终止后重试，不无限增加版本。

当前旧配置用于完成难度划分，不宣称已经满足新版障碍形状偏好。版本结果分别报告；自适应改场景后的结果用于任务设计校准，不当作独立held-out泛化测试。

难度阈值严格使用完整且通过审计的整轮数据。整体任务成功率＝成功trial数/全部186trial数，同时单独报告资源终止。校准用成功率＝成功trial数/非资源终止trial数，以免把上下文或GPU上限误解释为地形困难；六条件汇总和15类地形等权指标均保存。校准率 >40% 提高一档，<5% 降低一档，等于边界或位于区间内保持档位。最终若仍超出区间，记录校准边界，不无限尝试。

几何难度划分显式使用相机初始测距、目标像素大小、特权参考恢复视野动作数和参考到达动作数。经验难度单独按每场景六条件成功数描述：≥4成功是此基线的容易场景，1–3是中等，0是困难；资源问题单独标未解决。六次不同条件不能当独立重复采样，失败不等于已证明的内在任务复杂性。

最终指标包括六条件成功率、1000/2000/3000步成功率、恢复视野率与时间、成功所需动作/物理时间/路径、可行参考路径效率、碰撞/跌倒/越界、提前停止、预算耗尽、格式失败、资源终止、模型误报可见性和引用依据错误、上下文帧数/token数、推理耗时。路径效率使用实测可行参考路线，不是最短路径SPL。

模型、提示词、图像预处理、动作和成功判据在地形校准中保持同一条件，不偷偷把提示词改善计作地形改善。三上下文×RGB/RGB-D仍分别记录每次实际输入与完整输出。全部历史不截断，资源边界明确终止。原图与逐位无损深度记录保留。

场景丢失视野的准入暂沿用已有实体视线判据：纯转向出视野不合格；优先低起伏本身暂时挡住目标的场景。关于地形引起相机俯仰/高度变化而出视野的可选定义，已向用户提出澄清；未收到回答时不扩大已有准入条件。

浏览入口默认显示汇总和筛选。用户选一个trial/场景后才加载其图片；历史输入、完整提示词、完整原文和物理图按需展开。未完成整轮时页面不显示“最终成功率”。完成后生成 FINAL_REPORT.md、evaluation_metrics.json、difficulty_classification.json，以及跨版本 FINAL_RESULTS.json。
