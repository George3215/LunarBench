# 原生接口诊断后的判断和后续实验

本轮 105 次 GPU 推理已经完成。依据 REPORT.md、逐题原始输出和 FINAL_AUDIT.json 作如下判断。不能把这轮问答计成 105 个导航回合。

## 已有证据

1. Spatial-Interactor：21/21 共同单帧/双帧题正确；Qwen 和 RoboBrain 均为 20/21。与 Qwen 的差别只有一道方位题，不足以证明统计优势，也不涉及持续空间记忆或闭环导航。这支持继续作为候选底座，不能写成已经提升导航。
2. RoboBrain：原生 pointing 3/3 落在可见红球紧框内，误差 1.32、2.29、1.62 像素；grounding IoU≥.5 只有 1/3。两种定位指标不能互换。方位题一次把左右分区解释成上下分区，说明能输出精细目标点仍不保证自然语言动作语义可靠。
3. SpatialRGPT：原生 region mask 的左右题 3/3；原生深度分支的相机 RGB-D 受控变体 3/3。共用选择题 12/15，但 15 题中 14 题附带 ComponentPlacement 异常串，应与答案正确率一起报告。区域/深度分支可运行并有正确回答，不能据此前六动作接口的失败否定其所有空间能力。
4. SpatialReasoner：相同场景自定义单帧题 3/15。原生 think/answer 格式完整，许多错误回答自行生成图中未提供的三维坐标并进行不可靠计算；这是当前输入域上的负结果。尚未跑其官方基准或官方样例，不能推广成模型在全部任务上无效。
5. 所有模型最终回答均可按原生最终答案形式解析，无输出 token 截断。评分器保留 strict-letter 基线，随后统一支持闭合 think 后的最终字母、answer 标签、boxed 和任意选项的精确文字；未改模型输出或重跑挑选答案。Spatial-Interactor 的空 think 块不是推理失败。

RoboBrain 的三个原生点按相机内参换成粗略方位，均落在前进候选的 ±8° 死区内；三次结果均可得到 FORWARD 候选。详见 POINT_TO_MOTION_CHECK.json。**这是离线输出转换检查，没有执行动作，也没有判断前方道路能否通过。** 它表明六动作策略失败与原生目标定位能力应分开评估；不能断言先前转圈完全由 prompt 引起。

## 接下来最有价值的实验

### A. 相机/里程计坐标契约与空间状态传播诊断

固定并实测 body/camera 的前、左、上、yaw 正方向，确认 point→ray、camera→body、body→初始参考系的变换。使用相机可见红球的 RGB-D 初始粗定位和理想自身里程计，构造目标消失后的**带不确定性位置传播**题。评分来自同一已观测点经已知自身运动的解析传播；目标真值仅可作单独离线误差审查，不能补进输入。加入非零转弯、侧移、前进、累计位姿误差，避免只问能靠恒定方向猜中的题。

### B. 明确区分空间记忆与重现预测

位置传播可解析监督；障碍背面通常不可观测。重现概率、还需走多远、哪个动作最可能恢复视线，必须由实际分支 rollout 监督，带失败/截断和不确定性，不能从隐藏地图算出唯一正确答案再声称模型自行推断。优先采同一丢失状态下 2–4 条短分支，保存相机、里程计、目标可见性变化、碰撞/停滞和路径长度。

### C. 小规模闭环控制器验证后再扩大

先以 Qwen 和 Interactor 作同架构主对照。RoboBrain 用作者原生图像问答/pointing，再用显式传感器和控制器把预测点或子目标转成短动作；可见目标消失时停止使用当前 pointing，转为空间信念与候选通道判断。所有模型共用动作预算、控制器、目标确认和 STOP 门禁，清楚报告 VLM/控制器传感器差异。

先冻结三类场景的少量配对 pilot，分别记录目标定位、里程计更新、重新看到目标、接近进度和最终到达。只有通过预先约定的接口与输入审计，才跑完整 22 场景；不得把恢复可见或离线 FORWARD 候选写成到达。

### D. 论文可学习部分

将 A 的状态传播、B 的动作条件重现预测、执行后的信念修正作为可学习任务；再评估它们对 C 的实质提升。优先小规模 SFT/LoRA 与任务输出设计，保持不确定性显式、使用未见地形/遮挡类型测试。当前证据支持这个方向值得试，还没有产生创新收益结论。

本轮完成的是原生格式小样本接口和基础判断诊断。A–D 是后续工作，尚未声称已完成新的遮挡导航实验或模型训练。
