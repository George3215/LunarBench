# 目标短暂丢失后的预测与决策：量化实验设计

日期：2026-10-19。状态：建议协议，尚未实现或运行。本文件不改变既有实验结果。

## 论文要验证的假设

在目标最初可见、随后被真实几何遮挡、没有预先地图的条件下，轻量微调能够让 VLM 从视觉历史和自身运动中形成可用于行动的遮挡状态，并预测不同短动作序列恢复目标视线的可能性。与相同观测、控制器、数据和预算下的直接动作学习相比，这种预测是否提高恢复视线和最终抵达的表现？

区分三项主张：

* 目标位置传播：已观测点和自身位姿变换可通过解析计算完成，应作为强参考，不能单独主张 VLM 创新。
* 动作条件预测：给定相同目标方位，哪些可执行分支更可能恢复视线、多久恢复？这是主要学习对象。
* 反馈修正：新观察与预测不一致时，是否会修改判断，并改善实际决策？这是闭环贡献的验证对象。

Spatial-Interactor 已涵盖自身运动、可见性变化和长轨迹整合，并提供交互评测；因此“给 VLM 增加空间记忆/训练空间推理”这一宽泛描述不足以界定本工作的独立贡献。需要进一步核对该工作和主动目标搜索近邻，避免把本协议直接当成新方法证明。

## 实验一：同一丢失状态的短分支预测与选择

### 输入与状态冻结

固定首次目标消失时刻 t0。目标最初可见，随后经过统一的受控前缀被遮挡。保存完整仿真及低层控制器状态、随机数状态、相机、时间和观测历史，恢复后核对 RGB/深度与自身运动。只复制 qpos/qvel 不足以自动保证可重放。

模型可以看到：初始/最后可见/当前 RGB-D、相机内参或统一转换出的观测量、自身里程计、最近实际动作效果、候选动作序列。任何推导空间状态只能来自这些允许观测。

模型不可看到：目标真实世界坐标、隐藏几何、仿真物体 ID 或分割真值、完整地图、候选未来画面、候选的真实成功标签。评分器可读取这些信息验证目标身份与遮挡原因，但必须与模型请求隔离。

### 候选分支的明确语义

第一版固定 K=4、每个分支 6 个一秒动作，示例：

|分支|完整动作序列|
|---|---|
|前进|FORWARD ×6|
|向左绕行|STRAFE_LEFT ×2 → FORWARD ×4|
|向右绕行|STRAFE_RIGHT ×2 → FORWARD ×4|
|退回并扫描|BACKWARD ×2 → TURN_LEFT ×2 → TURN_RIGHT ×2|

这些是相同预算的局部探测分支，不是全局最优路线。分支库须在 pilot 后固定，在验证/测试集上不调整。若需增加转弯绕行分支，作为新协议版本，不能按测试标签为每个状态挑选候选。候选顺序打乱并保留稳定 ID，以排除位置偏好。

模型在执行前对所有候选输出：

* `p_reappear_6s`：执行该完整分支时，6 秒内稳定恢复目标可见性的概率。
* `time_if_reappears_s`：在该分支成功恢复的条件下，首次稳定恢复所需时间；可用区间表达。
* `selected_candidate_id`：选择的分支。
* 可选简短的可核查预测与不确定性，不把自然语言解释是否“像推理”当成主要分数。

随后由评分器分别恢复同一 t0，真正执行所有分支。分支相互独立，后执行分支的模型不能看到前分支结果。全部分支结果只用于离线评分和训练集监督，测试时不能替模型试完再选择。

恢复事件建议：精确目标身份对应的可见像素达到既有 20 像素门槛，连续 3 个 10Hz 采样可见，并保持 upright/in-bounds。模型输入侧仍使用允许的视觉检测，不提供精确分割。报告像素门槛对目标大小、分辨率的依赖，pilot 后锁定。

### 指标

令 y_ik 表示状态 i 的分支 k 是否在 6 秒内恢复；p_ik 是事前预测概率，c_i 是模型选项。

|指标|定义/报告方式|解释|
|---|---|---|
|选择后恢复率|mean(y_i,c_i)，所有有效状态都进入分母|实际是否选到了能恢复目标的局部分支|
|候选可恢复覆盖率|mean(max_k y_ik)|分支库的能力上限，避免把“全分支失败”都归咎于模型|
|可恢复状态中的选对率|sum(y_i,c_i)/sum(max_k y_ik)|至少一个分支可恢复时，模型是否选对；不能只报此条件指标|
|Brier 分数|mean((p_ik-y_ik)^2)，越低越好|预测概率与真实事件是否一致；同报事件正负比例和恒定概率基线|
|恢复时间误差|在实际恢复的分支上比较预测时间与首次恢复时间；报告预测缺失率|是否大致知道要执行多久；失败分支不能用时间 0 填充|
|代价|恢复所需秒数、动作数、平移路程和总转角|避免把原地扫描的零平移距离误认成零成本|
|碰撞/停滞/失稳|使用冻结的检测定义，报告事件率和持续时间|是否通过危险或无效动作获得视线|

6 秒未恢复的是“预算内未恢复”，不能标成“永远不会恢复”。时间/距离记录为截断或删失值，不填 0，也不能把这些分支从恢复率分母删除。不同状态、候选之间的样本相关性要保留。

若要评价预测的平移距离，可作为辅助指标；旋转可能在几乎零平移时恢复视线，因此以执行时间/动作步数为首要预测尺度。

## 实验二：预测是否真的改善闭环导航

从完全相同的 t0 启动各方法，让其自主恢复视线并接近目标。固定低层控制器、允许动作、相机、模型调用与输出 token 预算、最大 64 个一秒动作。每一或两个动作重新观察和修正，所有方法使用同一节奏。

短分支实验执行完整 6 秒以获取条件结果；闭环导航允许中途改计划。不能把一个已经中断的计划预测，硬与后来换路的结果比较；闭环预测误差只在语义一致的已执行区间或独立分支上评分。

主指标：

1. `Recovery@64`：预算内恢复稳定可见性的比例。
2. `Arrival@64`：沿用当前协议，目标确认可见、有效表面距离 <1m、upright/in-bounds，连续 3 个 10Hz 样本。
3. 恢复到抵达的转化率，同时保留 Arrival 的全回合分母。只重新看到、没有接近，不算抵达。
4. 所有回合的恢复时间分布，未恢复者按预算截断标记；成功回合的路程单列，不用成功样本的短路程掩盖大量失败。
5. 无效转动/停滞、碰撞/失稳、实际位移、VLM 调用数和墙钟耗时。
6. 合法 STOP 成功率单列，自动 Arrival 不冒充 VLM 自行正确停止。

不假定已知地形上最短可行路径。没有可靠最短可行路径长度时，不用直线距离冒充 SPL；可先报告成功率与实际代价。若后续用离线地图计算 SPL 的参考最短路，地图必须仅在评分器使用，且须符合机器人通行与成功终点定义。

## 对照：收益来自训练了什么

最少设置：

|组|模型与训练|要回答的问题|
|---|---|---|
|A|原始 Qwen，同样历史、RGB-D 和里程计，直接选择候选|基准能力|
|B|Spatial-Interactor，与 A 相同输入、候选和预算|已有空间训练是否自然迁移|
|C|Qwen，使用同一批分支状态与 action 标签微调，只学习选择候选|增加任务数据和微调本身能提升多少|
|D|Qwen，同源数据，联合学习分支重现概率/时间、空间状态与执行反馈修正|拟议学习目标是否有额外价值|
|E（强参考）|VLM 识别目标＋解析里程计记忆＋可见几何启发式选择|用已有工具就能达到多大程度|

另有关键诊断：给 A/B/C/D **相同的解析目标方位与误差估计**，再比较分支预测与选择。这样可排除优势仅来自更准确位置传播。此诊断与“模型自己维护记忆”的完整方法比较分开报告。

所有组的额外信息来源、图像处理尺寸、历史长度、候选生成器、解析状态是否输入、训练数据和实际训练计算量列成表。C/D 使用相同来源与划分的数据，报告样本/优化步数/实际 token 或算量，不把粗略相同 epoch 自动视为完全相同训练成本。

主要消融在最终 D 上进行：去掉动作条件预测监督；去掉执行反馈后的修正；去掉学习的记忆/状态更新但保留同一解析记忆参考。每次只变一个因素。不同基础模型只是对照，不是方法创新本身。

## 场景和样本计划

先用冻结 V4 做机制 pilot，不立即把全部 22 个准入地形当作已验证可到达的正式导航集。现有准入主要验证初始可见、真实遮挡和可重见；需另行验证到达可行性以及低层控制器能走过，避免将无解场景/低层失稳误作高层推理失败。准入标准不得依赖被比较 VLM 的成败。

建议第一阶段 30 个丢失状态 ×4 分支 =120 条短仿真 rollout；Qwen/Interactor 各在每个状态一次性预测全部分支，共 60 次模型决策请求。30 状态可用于接口、标签、候选覆盖与预算校准，不足以给出泛化或显著性结论。若 pilot 因接口修改重跑，保留旧版数据并换版本。

若机制成立，按整个物理布局划分训练/验证/测试；同一布局的所有前缀、丢失时刻、候选分支、目标位置微扰不得跨集合。不能把轨迹帧随机切分。新增布局变化真实几何、起点/目标和遮挡路径，不只换随机纹理。

初期训练数据可从 500–2000 个状态、2000–8000 条分支起步，学习曲线验证数据量是否足够，不把这个数量视为保证。训练标签来自实际执行和允许传感器/独立评分器；无需人工为每条轨迹编写长推理文本。

正式测试可先规划约 100 个独立未见布局的任务，再根据 pilot 的成对分歧率和可检测收益确定最终样本量；100 不是统计功效保证。多个起点共享布局时，以布局为统计簇，不能当成完全独立样本。训练随机种子与物理任务种子分开，确定性仿真中重复同一次 greedy 运行不增加独立证据。

分层报告：

* 遮挡类型：墙角/实体障碍、坡脊/凹地、门窗/狭窄可见通道。
* 初始目标距离、遮挡后所需绕行距离、可恢复候选数量。
* 只有转头出视野的对照、没有持续目标丢失的对照，避免把简单找回画面目标等同真实遮挡规划。
* 理想里程计主实验；有标定依据的深度/里程计噪声与位姿漂移作鲁棒性测试，不能用无依据的噪声范围声称真实传感器可靠。
* 训练未见的遮挡几何类别与目标外观。只有红球月面结果时，结论限制为这类仿真目标恢复；若主张一般语义物体导航，需要其他目标类别/干扰物及跨场景证据。

统计：优先报告 D−A、D−C、D−E 的配对成功率差与按物理布局聚类的 95% bootstrap 区间；预先指定 Arrival 为最终主终点、Recovery 为关键机制终点。小样本可用 exact McNemar 检查二元成败的成对分歧，但重复时刻/同布局不能直接套独立样本检验。多个诊断指标与多方法对比标明探索性，不事后只挑显著项。

## 如何变成论文证据

|论文问题|必需证据|不能替代它的结果|
|---|---|---|
|现有能力缺口是否存在|同一状态下，空间问答/方位正确但分支选择和 Arrival 仍失败的配对案例与统计|只有一张失败截图|
|学习到了动作后果预测吗|未见布局上的概率分数、选择恢复率、时间误差及对照 C|训练集 loss 下降或长解释|
|预测对决策有贡献吗|控制其余因素后的去预测消融与闭环 Recovery/Arrival 差值|只报告预测更准|
|反馈修正有贡献吗|去修正消融、预测失配后的行为与闭环收益|日志中出现“我应该改路”|
|不是仅靠外挂定位工具吗|解析记忆强参考，且 D 优于同数据直接动作训练 C|比没有里程计的弱基线高|
|能推广吗|未见物理布局、遮挡类别、目标变化与噪声测试|同一个地图换多个随机数|

论文主张应随结果收缩：只有 Recovery 提升、Arrival 不提升，说明恢复观察环节改善但任务仍受接近或控制限制；只有加解析记忆就能改善，说明主要贡献是系统设计而非学到新能力；D 不优于 C，不能声称预测监督优于常规动作微调。负结果仍可指导方法修改，但不自动构成方法创新。

该设计与投稿专题的部分观测、主动感知、决策不确定性、基础模型和感知—执行反馈主题相符。专题强调物理具身和真实部署，若仅做仿真，应准确限定证据；跨平台或小规模真机可增强外部有效性，但页面并未把真机列为所有稿件的硬性条件。相符不意味着保证录用。
