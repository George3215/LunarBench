# VLM 在间歇目标可见性下的足式目标导航：算法研究设计

2026-10-04；状态：拟议方法与实验协议，尚无新方法结果。

1. 论文定位为 New Algorithm Paper，目标是改善 VLM 驱动机器人完成任务的能力。
2. 相机是策略观察环境的实际入口。相机与几何标签不同不是研究主张；禁止用 simulator 目标坐标代替视觉观测。

## 1. 研究问题与贡献边界

候选题目：Memory-Conditioned Predictive Planning for VLM-Guided Legged Goal Navigation under Intermittent Visibility。

问题：如何让 VLM 利用过去实际观测到的目标和执行历史，预测地形约束下动作对未来观测及接近目标的影响，从而在目标暂时不可见时继续可靠地到达目标？

任务不是首次提出 ObjectNav、主动感知、目标搜索或 POMDP。算法贡献应落在特定的记忆表示、执行后果预测、二者与 VLM 的结合或训练目标上。现阶段是待验证设计，不声称已证明新颖性。

核心比较：同一 VLM、相同传感器及低层控制器下，所提方法对完整目标到达率、效率和泛化的改善。

如果基础 VLM 冻结，仅添加外部记忆/规划，准确表述为“增强 VLM 驱动智能体/系统的具身任务能力”。若声称 VLM 本身获得可迁移能力，需微调或蒸馏后去除外部模块，再测试所得模型的能力。

## 2. 完整任务和权限

流程：接收目标描述或参考图像 → 视觉确认目标 → 执行接近 → 可能丢失目标 → 利用历史/预测恢复有效观测或继续绕行 → 接近指定目标 → 主动停止。

主任务允许目标持续可见；目标丢失子集用于诊断。不得仅保留必须丢失或复杂方法获胜的 episode。

终止成功必须同时满足：

- 到达指定目标的可通行邻域，而不是隔墙接近、上下楼层平面距离接近或接近错误物体；
- 最近真实相机证据确认正确目标，且策略发出 STOP；
- 机器人保持稳定，未触发约定的碰撞/越界等失败；
- 在统一任务预算内完成。

目标邻域半径、证据时效和稳定时间根据平台尺寸、任务用途和开发集校准后固定。可先考察 0.5/0.75/1.0 m 的候选半径；这些是开发候选，非已经验证的标准。不要把成功变成持续贴近物体或碰撞。

主指标为完整到达成功率。恢复可见率、恢复后到达率、错误 STOP 和重复丢失次数均为诊断指标。

权限分层：

- 策略：实际 RGB-D、目标指令/参考图、允许的 IMU/关节与带明确误差模型的里程计、历史输入和动作记录。
- 策略地图/记忆：只由上述传感器观测估计产生；估计目标位置可以用，但不得复制 simulator 真值。
- 仿真/评价器：目标身份、实际位置、接触和地图真值可用于生成环境、算成绩、验证可通行目标区域；不返回策略。
- 学习监督：若离线训练使用 privileged labels，单独声明来源与测试时无真值条件；不把它描述成纯相机自监督。
- 预测未来：部署策略调用学习模型，不能通过克隆真实隐藏世界并 rollout 候选动作获得答案。真实分支枚举仅为离线训练/诊断或明确标注的 oracle。

工程上由环境 step 固定获取相机包并传给策略，不依赖 Agent 自愿调用相机工具。每次策略决策保存图像哈希、时间戳与输入清单，禁止静默回退到几何标签。

## 3. 现有结果的准确位置

旧 Image+Memory+Action 是 RandomForestClassifier；Image 是 4×4 深度网格与 RGB 均值，Memory 是最后检测的质心、深度和年龄。它不是完整视觉编码器、VLM 或世界模型。

因此旧负结果只能说明该数据集上这套表示/评分器未显示优势。它不能证伪 VLM+记忆/世界模型，也不能证明它们必然有效。旧单步 0.739 等结果不是新任务的基线成绩，所有主表方法都必须在新的完整到达协议下重新运行。

## 4. 候选算法（待实现与对照核查）

### 4.1 记忆状态

m_t 保存目标关键帧、身份置信度、最后可靠深度/方位、相对位姿估计及不确定性、已经尝试的路径/动作与结果。采用丢失、恢复、显著视点变化和执行失败等事件进行检索或更新；与同 token 预算的均匀采样历史比较。

不能把所有过去图像无限堆进上下文，再把额外 token 与调用次数带来的提升归为算法机制。

### 4.2 预测状态与转移

令 z_t = E(o_t, m_t, proprio_t)。训练动作条件预测器：

p_theta(z_{t+1}, delta_pose, detection_quality, collision_or_fall, goal_progress | z_t, a_t)。

模型要刻画执行偏差：同一个“向前”指令在平地、上下坡和台阶上不等于相同的实际位移和相机变化。可采用潜空间预测，不要求生成完整视频。

如果实现只输出单次成功概率，应称 outcome predictor。称世界模型时，应有可递推状态转移、多步预测及其预测质量验证。遮挡目标的位置应保持分布或多个假设，不把幻觉位置当成确定真值。

### 4.3 与 VLM 的结合

VLM 根据目标、当前帧和检索到的历史提出少量有语义的动作/短序列，例如回到最后观察位姿、绕过遮挡、爬上可通行台阶后重新观察、沿可见通道接近目标。

预测器对序列估计未来观测、可执行性及到达进展。将结构化预测和不确定性反馈给 VLM，或由统一优化器选择动作，执行首段后重新观察与规划。第一版保持同一低层控制器不变。

目标函数候选：预测终端到达价值 + 沿途任务进展 + 适度的信息收益 − 路径/时间代价 − 碰撞/失稳风险 − 预测不确定性惩罚。

“看到目标”不能作为全部奖励，否则会停留在舒适观察点。短期绕远、暂时失去目标的动作，只要有利于最终可达目标，都应被允许。

可能的技术贡献是历史条件下对观测恢复、运动执行和到达进展的联合建模及闭环利用，不是 VLM+WM 两个名词的拼接。NaVILA/WoMAP 已有明显重叠，需做具体技术对照。

## 5. 部分可观测性：三个层次的证据

### A. 问题建模

有限视野与遮挡使单帧无法一般性恢复完整环境状态，足以采用 POMDP 建模。算法论文不必额外证明“所有无历史策略无法成功”。

### B. 受控信息歧义实验

构造两个等概率世界 W_L/W_R：同一目标分别处于左右被遮挡的分支。机器人此前真实看见目标在不同分支；回到共同决策位置后，当前 RGB-D、本体状态、允许的里程计、时间、上一动作等全部输入一致，低层控制器状态也匹配。目标不在当前视野内，不得通过阴影、反射、随机种子或 scene ID 泄漏位置。

采用物理可执行历史到达共同状态；如需恢复快照进行精确匹配，明确它是受控诊断，与自然整段任务分开。历史证据来自各自真实观测，不使用编造叙述。

设置合理的固定预算，使任一正确分支均能到达目标，而走错后检查另一个分支来不及；分支承诺前不提供区分世界的额外线索。用实际执行验证时间可达性，不仅依赖绘图。

在这些明确假设下，不使用此前历史、接收完全相同输入的策略无法在首次分支选择时区分两个世界，其平均正确率最多 1/2。若两条路径都能在预算内访问，此成功率界不成立；改为比较错误探索带来的额外时间/距离。对近似相同图像只能报告经验歧义，不宣称精确界。

统计实验：当前帧 VLM、普通历史帧 VLM、所提记忆 VLM、错误历史干预、简单记忆地图基线。报告分支选择、完整到达、额外距离及随遮挡/历史间隔长度的变化。

这个实验分离“当前输入缺信息”和“模型没学会使用已有信息”。它证明该条件下历史有决策价值，不证明只有 VLM 能用历史。

### C. 主任务中的实际增益

使用未参与设计的布局与自然任务轨迹，比较相同 VLM 的历史消融、历史长度和检索方式。物理重复与模型采样重复分开统计。

训练时无历史的模型需从头按对应条件训练；测试时打乱历史另作干预，避免将分布外破坏当作必要性证明。历史交换优先在成对受控环境中匹配时间/尺度/轨迹背景。

若报告 I(A*;H|O)>0，只能针对明确的离散受控生成模型解析计算或谨慎估计；有限分类器性能差不能直接证明真实条件互信息为零或严格为正。算法论文主线不需要依靠该量。

## 6. 核心方法矩阵

所有方法使用相同可用传感器、动作接口、停止条件和低层控制器。区分信息消融与相同信息预算下的算法比较。

| 编号 | 方法 | 回答的问题 |
|---|---|---|
| B0 | 前进、扫描、里程计回退与目标可见时的视觉接近规则 | 新完整任务的简单下限与强规则参照 |
| B1 | 单帧 VLM 闭环 | 基础模型是否在失去目标后失效 |
| B2 | VLM + 均匀/最近历史帧 | 直接给历史是否已经足够 |
| B3 | VLM + 所提记忆，不用预测 | 记忆设计的独立增益 |
| B4 | VLM + 预测，无显式历史 | 预测的独立增益；预测器不得暗含未声明的递归历史 |
| B5 | VLM + 所提记忆 + 预测规划 | 完整算法；预期更好是研究假设，不是既定结果 |
| B6 | 同信息的视觉地图/目标定位 + 路径规划 | 经典方法在完整任务上的实际竞争力 |
| B7 | 同记忆+预测器，规则/均匀候选替代 VLM 提议 | VLM 在所提系统中的具体作用及模块归因 |
| B8 | 最接近的可复现现有方法 | 根据 NaVILA/WoMAP 等任务/接口差异选择并清楚标注适配 |

B2/B3 的图像数量、token、调用次数需对齐；B4/B5 的预测采样与计算预算需对齐。另报告原始模型和参数/数据规模匹配的普通微调模型，若所提方法进行了训练。

不把 B6/B7 看成“必须证明 VLM 存在必要性”的门槛；它们用于显示任务难度、效率和各模块的作用。

## 7. 仿真实验清单与优先级

### 必做主表

1. 完整到达任务：未见布局/起点/目标的 end-to-end success、路径效率、错误停止、失败类型。
2. B1–B5 同 VLM 消融；强传统与最接近文献方法对比。
3. 地形×方法的配对实验：flat、rough、up-slope、down-slope、up-stairs、down-stairs。
4. 可见性条件：持续可见、短暂遮挡、重复丢失/需绕行；遮挡是独立轴，不能与 rough/slope 混作一个地形类别。
5. 受控观测歧义与历史利用；作为机制证据，不代替主表。
6. 未见目标外观/类别和同类干扰物；实际视觉识别与身份关联，不以唯一红球支撑开放词汇泛化。

### 支撑机制与鲁棒性

7. 预测模型的多步误差、可见性/失稳概率校准与规划效果；预测准确率只是机制指标，最终看实际到达。
8. 深度缺失、位姿漂移、视觉噪声、光照和相机抖动，先单因素后组合；只报告实际模拟的噪声，未模拟 motion blur 不称已验证。
9. 不同 VLM backbone 至少作为拟议迁移实验；冻结算法超参数后迁移并报告变化。只测一个则限定结论。
10. 计算与数据效率：物理时间、决策延迟、VLM 调用/token、训练数据量与额外模块开销。
11. 跨任务初步迁移：同一算法用于普通目标接近、途中遮挡恢复、到达指定观察位姿等；若要声称改善抓取或一般 VLM 能力，必须增加对应任务或明确为未来方向。

### 后续增强

12. 不同低层控制器/机器人形态；对应跨平台主张，非当前仿真阶段的强制前提。
13. 真机验证：使用相同观测/记忆/动作接口，检查实际感知误差和延迟；本计划不授权或执行真实机器人运动。

地形机制实验需记录实际坡度、粗糙度/相关长度、台阶高宽、目标高度与初始投影，而不只用名称。保持目标身份和基础平面布局配对，因改变地形产生的初始成像差异要报告。pit/trench 可作为可通行约束压力测试，不能将不可达目标悄悄计为方法失败或结果后删除。

主表直接接近目标；单独提供低层控制器跟踪可行参考路径的诊断，区分高层选择失败与低层控制器能力不足。oracle 控制器或真值路径仅为诊断。

## 8. 规模与统计的可执行预算

先导资源建议：6 地形 × 3 可见性条件 × 4 基础布局 × 2 起点/扰动重复 = 144 episodes/方法。

正式测试预算草案：6 × 3 × 20 × 3 = 1080 episodes/方法。对每种可见性条件，20 个基础布局在六种地形间配对，因此不是 1080 个独立布局；主要独立单元是 60 个布局族。约 8 个核心方法对应 8640 个测试 episodes，训练数据另计。

这些数字是工程预算建议，非发表或功效保证。先导估计布局间方差、失败率与成本后调整，并在独立确认测试前冻结。若预算不足，优先保持独立布局数量，精简非核心组合，不把同轨迹帧数或 VLM seed 当成独立实验。

- 布局族、成对世界和资产近重复保持同一数据划分。
- 因地形是配对变量，分析方法×地形差异，按基础布局聚类，物理重复嵌套处理。
- 比较到达成功率、完整成功随预算变化、路径长度；SPL 必须使用可通行的参考路径而非穿墙欧氏距离，并说明足式参考路径的近似方式。
- 失败不从效率统计中消失；报告预算截尾结果或预先定义失败惩罚。
- 记录所有无效初始化、不可达和物理失败；纳入规则在看策略结果之前固定。
- VLM 温度、模型版本、图像尺寸、提示词、调用次数、缓存与费用记录可复现；共享前缀输入可以缓存，不跨不同状态伪共享模型答案。

## 9. 论文应如何写

主文：VLM 在目标间歇不可见和受地形约束的到达任务中的困难 → 提出的历史条件预测/规划机制 → 完整到达任务 → 同 VLM 改进、模块归因、泛化和成本。

相机权限、特权状态隔离写入实现与协议；历史 bug 审计和旧单步评分器结果保留为独立技术材料。不要继续让 camera-vs-geometry 的 91.67% 成为摘要主结果。

可用的动机表述：

“VLMs provide a reusable semantic interface for embodied tasks, but selecting executable actions toward a temporarily unobserved goal requires maintaining visual history and reasoning about action-dependent observation and motion outcomes. We investigate a memory-conditioned predictive planning method to improve VLM-guided goal navigation under these conditions.”

这段是研究动机，不是结果。不要预写优于所有基线、必要性或普适能力提升。具体创新点需依据 RELATED_WORK.md 中最接近方法进一步界定。
