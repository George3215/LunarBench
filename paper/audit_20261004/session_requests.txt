可以把目前的讨论压缩成一条非常清晰的研究路线。**第一个实验不要追求“完整论文方法”，而是先验证最核心的因果关系：机器人在目标丢失后，提前想象不同动作的结果，是否真的能帮助它选择重新看到目标的动作。**

# 1. 我们目前确定的研究问题

我们不是研究：

* 普通 Object Detection
* 普通 Object Search
* 普通 Active Perception
* SLAM / 全局地图
* 单纯 World Model
* 单纯 VLA/VLM 导航

而是研究：

> **机器人曾经观察到目标，但由于自身运动、地形几何或遮挡，目标暂时不可见；机器人如何利用目标历史信息，对候选动作产生反事实未来，并选择能够使目标重新进入可观测状态的动作？**

暂定名称：

> **Target Re-observability Planning**

核心思想：

$$
\boxed{
\text{Target Memory}
\rightarrow
\text{Candidate Actions}
\rightarrow
\text{Counterfactual Imagination}
\rightarrow
\text{Future Observability}
\rightarrow
\text{Action}
}
$$

---

# 2. 最关键的 motivating example

我们最终选定的最小例子是：

### 十级楼梯

机器人最初能够看到十级楼梯上的目标。

然后机器人向楼梯靠近：

```text
Target
  ●  Level 10
 / 
/
/
Robot ● Level 1
```

目标突然因为楼梯几何关系消失。

此时机器人有多个动作：

```text
A1：相机抬头
A2：左转
A3：右转
A4：向前走
A5：上楼
```

可能得到：

```text
A1 → Target 不可见
A2 → Target 不可见
A3 → Target 不可见
A4 → Target 不可见
A5 → Target 重新可见
```

这个例子证明了一个非常重要的事情：

> **Target Re-observation 不一定是改变观察方向，有时必须通过物理运动改变机器人位置。**

所以你的问题实际上不是简单的：

> “Where should I look?”

而是：

> **“What should I do next so that I can see the target again?”**

这是目前整篇工作的核心。

# 3. 我们对已有工作的结论

我们已经讨论过几个方向：

### Lost Target Search

已经存在“目标离开 FoV 后主动重新寻找”的研究。

所以不能宣称：

> 首次研究目标丢失后的重新搜索。

---

### Active Perception

已经研究主动改变观察行为获取信息。

所以也不能宣称：

> 首次使用主动感知解决目标重新观察。

---

### Object Search

目标搜索本身已经是成熟方向。

但你的设定不同：

> **目标不是从来不知道在哪里，而是机器人之前已经观察过它。**

---

### World Model Planning

WoMAP、NavWAM 等已经证明：

> Candidate actions → World Model → Future prediction → Action selection

这个范式本身不是你的创新。

因此不能把：

> “Agent + World Model + Candidate Actions”

作为核心创新。

---

# 4. 真正留下来的研究缺口

我们的定位最终收缩到了：

> **Previously observed target + currently invisible + physical action changes observability + counterfactual action-conditioned prediction**

也就是：

```text
Target observed
      ↓
Target lost
      ↓
Target memory remains
      ↓
Generate candidate physical actions
      ↓
Imagine future consequences
      ↓
Predict target observability
      ↓
Choose re-observation action
```

因此目前最核心的创新假设是：

$$
P(V_{t+H}=1|O_t,M_t,a)
$$

其中：

* \(O_t\)：当前观察
* \(M_t\)：目标历史记忆
* \(a\)：候选动作
* \(V\)：未来目标是否可见

选择：

$$
a^*
=
\arg\max_a
P(V_{t+H}=1|O_t,M_t,a)
$$

# 8. Counterfactual Rollout

关键来了。

机器人**不真正执行**动作。

而是在 MuJoCo 中复制当前状态：

```text
Current State
     │
     ├──→ Camera Up      → Future State 1
     │
     ├──→ Rotate         → Future State 2
     │
     ├──→ Forward        → Future State 3
     │
     └──→ Climb          → Future State 4
```

分别向前模拟 \(H\) 步。

然后判断：

$$
V_{t+H}^{(i)}
$$

# 9. 第一个实验最简单的决策器

```python
for action in candidate_actions:
    future_state = mujoco_rollout(current_state, action)
    visible = check_target_visibility(future_state)

choose action with visible == True
```

例如：

| Action    | Target visible | Cost |
| --------- | -------------: | ---: |
| Camera Up |              0 |  0.1 |
| Rotate    |              0 |  0.3 |
| Forward   |              0 |  0.5 |
| Climb     |              1 |  1.2 |

选择：

```text
Climb
```

然后**只有被选中的动作才真正执行**。

* 转动
* 能耗

# 16. 当前论文的核心故事

最后可以浓缩成：

> **现有目标搜索通常关注“如何找到未知位置的目标”，而目标重新可观测问题关注“如何重新看到一个已经被观察过但因自身运动和环境几何而暂时不可见的目标”。为此，我们让机器人保留目标历史信息，并对候选物理动作进行反事实未来预测，根据预测的目标可观测性选择动作，从而避免盲目搜索。**

# 1. 可以统一成一个现象：非单调可观测性

机器人沿着一条路径运动：

$$
s_0\rightarrow s_1\rightarrow s_2\rightarrow ...\rightarrow s_n
$$

目标可见性：

$$
V(s_0),V(s_1),...,V(s_n)
$$

普通直觉认为：

```text
离目标越来越近
        ↓
越来越容易看到目标
```

但你的场景可能是：

```text
远处       中间          近处
 │           │             │
 ↓           ↓             ↓

  👁 ─────────────────→ ●
   \                    Target
    \
     \

Visible      Visible       Invisible
```

甚至：

```text
Distance:

10m    8m    6m    4m    2m

 V      V     X     X     X
```

然后机器人继续运动：

```text
2m     1m
 X  →   V
```

所以：

$$
V(d)
$$

并不是距离的单调函数。

这就是一个很好的研究现象。

> **Terrain-Induced Target Re-observability**

下面是四个典型机制。

也就是：

$$

```text
        \
         \
          \
```

# 6. 这样你的问题就从“Lost Target”变成了一个更漂亮的概念

我建议定义：

## **Non-monotonic Target Observability**

即：

> **机器人与目标距离不断变化时，目标可观测性并不一定单调增加，而可能由于地形几何和机器人位姿变化发生多次 Visible → Invisible → Visible 转换。**

然后你的研究问题变成：

> **当目标可观测性具有非单调性时，机器人能否利用历史观测和动作条件未来预测，主动选择能够恢复目标可观测性的动作？**

这个比“楼梯上找目标”强很多。

---

# 7. 这也正好解释为什么 History 是必要的

考虑：

```text
远处
Target ✓
   ↓
靠近
Target ✗
```

当前状态：

```text
Target invisible
```

机器人只看当前 RGB：

```text
       Current RGB
            ↓
     Target invisible
            ↓
       我该去哪？
```

可能没有答案。

但是 History 告诉它：

```text
过去：
Target 在右前方、较高位置
```

所以：

```text
History
   ↓
Target likely behind/above terrain
   ↓
应该改变位置，而不是随机转头
```

因此你的 History 不是简单的“记住上一帧”。

它提供的是：

> **目标的历史空间约束。**

## 1. Lost Target Search：最直接的前身

### Radmard & Croft, Autonomous Robots 2017

**Active Target Search for High Dimensional Robotic Systems**

他们定义的就是：

他们利用 **target 在消失之前的最新信息**，在线生成 search action，并考虑机器人运动约束。实验包括 7-DoF eye-in-hand 机器人。([Monash University][1])

所以：

$$
\text{target lost}\rightarrow\text{active recovery}
$$

**不是你的新问题。**

### 和你不同在哪里？

他们关注的是：

> **如何高效搜索已经丢失的 target。**

你现在关注的是：

> **为什么在 terrain-induced partial observability 下，target 的可观测性随机器人运动呈非单调变化，以及历史信息和物理动作如何决定下一次 re-observation。**

# 二、Occlusion-aware active target search

### Radmard et al., IEEE T-RO 2018

**Resolving Occlusion in Active Visual Target Search of High-Dimensional Robotic Systems**

这个工作更接近你。

他们：

* particle filter 估计 target location；
* 建立 occluder boundary；
* 规划能够“绕开遮挡”的 motion；
* 同时考虑 information gain 和 motion cost；
* 在线寻找能够重新看到 target 的动作。([Monash University][2])

也就是说：

$$
\text{target hidden}
\rightarrow
\text{estimate target}
\rightarrow
\text{find viewpoint/motion}
\rightarrow
\text{re-observe}
$$

### 和你不同

他们核心是：

$$
\boxed{\text{occlusion resolution}}
$$

你的核心可以是：

$$
\boxed{\text{terrain-induced target re-observability}}
$$

区别尤其在于：

**他们的 occluder 是一个需要被绕开的视觉遮挡结构；你的机器人运动本身会改变 terrain-induced visibility。**

```text

target visible

target invisible

target visible
```

所以：

$$
\boxed{\text{Closer}\not\Rightarrow\text{More Observable}}
$$

这是你 Experiment 2 最重要的结果。

# 三、Object Permanence / History

### Liang et al., 2021

**Improving Object Permanence using Agent Actions and Reasoning**

这篇非常重要，因为它已经证明：

已经有人做了。

# 九、那下一步实验到底做什么？

# Experiment 1：History Necessity

**验证的不是“history 有没有帮助成功率”。**

而是：

$$
\boxed{
\text{Current Observation alone cannot determine the optimal re-observation action}

设计成：

```text

             ↓
当前 observation O

Episode B

             ↓
当前 observation O'
```

要求：

$$
O\approx O'
$$

但是：

$$
a_A^*\neq a_B^*
$$

例如：

```text
             Current observation
                  ≈ same

          ┌────────┴────────┐
          ↓                 ↓
       History A         History B
       target left       target right
          ↓                 ↓
        LEFT              RIGHT
```

```text
geometrically visible

      ↓
```

因为 terrain / controller / body motion 等原因，**“这个 viewpoint 好”不等于“这个 action 好”。**

已有主动目标搜索工作实际上也会把目标信息收益与 sensor action cost、运动规划结合，而不是只做静态 visibility 判断。([Monash University][1])

$$

但：

$$

$$

而且你做到了更强的：

$$

$$

### 当前结果

* 8/8 optimal action different
* 8/8 无共同成功动作
* pixel difference：

  * HistoryOnly = 0
  * HeadingLock = 0

因此 H1 是目前非常强的一条证据。

### 它证明什么？

不是“某个 baseline 很差”。

而是：

$$
\boxed{
\text{当前 observation 本身不足以确定正确的 re-observation action}
}
$$

也就是**partial observability 是任务的结构性困难，而不是算法实现不好。**

# 2. H2：Target Memory 仍然不足

> “不存在一个固定动作可以成功。”

$$

也就是：

# 1. RSR 是什么？

你现在使用的：

$$
\boxed{RSR@K}
$$

可以定义为：

> **Re-observation Success Rate within K actions**
> 在最多允许执行 \(K\) 个动作的预算内，机器人能否重新看到此前丢失的目标。

对第 \(i\) 个 episode：

$$
r_i(K)=
\begin{cases}
1,&\exists h\le K,\;V_{t+h}=1\\
0,&\text{otherwise}
\end{cases}
$$

于是：

$$
\boxed{
RSR@K=
\frac{1}{N}\sum_{i=1}^{N}r_i(K)
}
$$

例如 16 个历史 paired worlds：

如果：

* 10 个在最多 3 步内重新看到目标
* 6 个没有

那么：

$$
RSR@3=\frac{10}{16}=0.625
$$

---

## 为什么不直接用 Success Rate？

因为你的任务不是普通的：

> 成功 / 失败

而是：

> **需要采取多少物理动作才能重新获得目标可见性。**

例如：

```text
A: right → target visible
B: right → right → target visible
C: right → left → back → target visible
D: right → right → left → right → ...
```

四个任务最后都成功，但它们的**re-observation difficulty**完全不同。

所以：

$$
RSR@1
$$

回答：

> 能不能一步重新看到？

而：

$$
RSR@3
$$

回答：

> 三步以内能不能重新看到？

$$
RSR@5
$$

回答：

> 五步以内能不能重新看到？

---

# 2. RSR@K 还有一个非常重要的优点

它天然适合你的：

$$
1\rightarrow0\rightarrow1
$$

以及：

$$
1\rightarrow0\rightarrow1\rightarrow0\rightarrow1
$$

这种**非单调可观测性**。

因为你的目标不是：

> 一直保持可见。

而是：

$$
\boxed{
\text{lost target}\rightarrow\text{physically move}\rightarrow\text{re-observe}
}
$$

因此 RSR@K 比单纯 final success 更符合任务定义。

---

# 3. 但是 RSR@K 不能单独使用

建议论文中同时报告三个指标：

### ① RSR@K

$$
RSR@K
$$

重新看到目标的成功率。

---

### ② Re-observation time

$$
T_{reobs}
$$

从 target lost 到第一次重新看到目标需要多少时间。

---

### ③ Action Cost

$$
C_{action}
$$

用了多少动作/运动量。

于是可以避免一种情况：

> 一个方法 RSR 很高，但是疯狂来回走。

所以最终：

$$
\boxed{
RSR@K + T_{reobs}+ActionCost
}
$$

会比单一 Success Rate 更完整。

> “这些是实际机器人在复杂环境中可能遇到的 target re-observation situations。”

$$

$$
V_{t+H}\in\{0,1\}
$$

目标：

$$
\boxed{
a^*_{t:t+H}

$$

\frac1N
\sum_i
\mathbf 1
[
\exists h\le K,\ V_{i,t+h}=1
]

现在最关键的一点

你之前的实验开发阶段已经结束了。

现在不要再问：

“还应该研究什么？”

应该改成：

“现有结果能不能形成一条不可被轻易攻击的论证链？”

而你现在这条链已经基本成立：

$$ \boxed{ O \not\Rightarrow a^* } $$ $$ \boxed{ O+M \not\Rightarrow a^* } $$ $$ \boxed{ G\neq P } $$ $$ \boxed{ Localization\neq Re\text{-}observability } $$ $$ \boxed{ P(S_{future}|O,M,a) \text{ is informative} } $$ $$ \boxed{ Prediction\rightarrow Decision\rightarrow Re\text{-}observation } $$

$$ \boxed{ Better\ prediction\not\Rightarrow Better\ decision } $$

在 safety 和 long-horizon 两个方向上都得到了实验证明。

所以我建议你现在就进入“Final Results Audit”，不要再开新的研究支线。

# 一、第一步：先证明你的任务到底需要什么能力

你现在的任务不是普通导航。

可以把任务拆成：

$$
\boxed{
\text{Re-observation}
=
\text{Perception}
+
\text{Spatial Reasoning}
+
\text{Temporal Memory}
+
\text{Action Consequence}
+
\text{Embodied Decision}
}
$$

具体来说：

| 能力     | 你的任务是否需要 | 例子                   |
| ------ | -------- | -------------------- |
| 目标识别   | ✓        | “刚才看到的是那个红色目标”       |
| 遮挡判断   | ✓        | “目标不是消失，而是被地形挡住”     |
| 空间关系   | ✓        | “目标在我右前方、低于当前视线”     |
| 深度/高度  | ✓        | “这里是一个凸起的地形”         |
| 时序记忆   | ✓        | “我刚才从这里移动过来时还能看到目标”  |
| 自身运动理解 | ✓        | “我向前走 1 m 后目标消失”     |
| 动作后果   | ✓        | “向左走可能重新看到目标”        |

这里就出现一个很重要的研究问题：

> **现有 CNN/MLP/几何方法能不能完成这些能力？**

如果能，VLM 就没有必要。

所以你必须先做这个实验。

# 二、其实已经有文献支持“空间推理是 VLM 的一个瓶颈”

这部分可以作为**文献论证**，但不能替代你自己的实验。

例如 SpatialVLM 的工作直接研究了 VLM 的空间推理能力，比较了 GPT-4V、LLaVA、InstructBLIP、PaLI、PaLM-E 等模型在定量空间关系问题上的表现，并进一步针对空间 VQA 训练模型。其结果说明普通 VLM 在距离等空间定量推理上存在明显不足，而专门加入 spatial supervision 后可以明显改善。([arXiv][1])

更有意思的是，2025 年的 MV-RoboBench 专门评估了**机器人场景中的多视角空间推理**。它发现，即使是当前强 VLM，在机器人多视角空间任务上仍明显落后于人类，而且普通 single-view spatial benchmark 的强表现并不可靠地转化成 robotic spatial reasoning 能力。([arXiv][2])

这对你反而是好消息。

因为你的论文可以提出：

> **现有 VLM 已经表现出一定 spatial reasoning 能力，但 robotic re-observation 需要进一步结合 temporal observation、ego-motion 和 action consequence。**

也就是说，你不是：

> “VLM 很厉害，所以我要用 VLM。”

而是：

> **“已有研究表明 VLM 可以提供一般空间推理能力，但现有空间能力不足以直接完成 embodied re-observation；因此我们研究如何将这种能力迁移并适配到目标重观测 Agent。”**

这就科学很多。

# 一、首先重新定义你的科学问题

## 1.1 最核心的一句话

我建议论文正式问题定义使用：

> **Given a target that has previously been observed by an onboard camera, can an embodied agent actively select physical actions to recover target visibility after the target becomes occluded by terrain, using only egocentric visual observations, observation history, action history, and robot self-motion?**

中文：

> **对于一个曾经被机载相机观测到、随后因地形遮挡而从视野中消失的目标，机器人能否仅利用自我中心视觉观测、历史观测、历史动作和自身运动信息，主动选择物理动作改变观察视角，使目标重新进入相机视野？**

这里有三个关键词：

$$
\boxed{\text{Previously Observed}}
$$

$$
\boxed{\text{Lost from View}}
$$

$$
\boxed{\text{Actively Re-observed}}
$$

这三个条件共同定义你的问题。

# 二、数学建模：它本质上是一个部分可观测的主动观测问题

## 2.1 隐状态

定义环境真实状态：

$$
s_t =
\left(
x_t^R,\;
x^T,\;
\mathcal{E},\;
c_t
\right)
$$

其中：

* \(x_t^R\)：机器人真实位姿；
* \(x^T\)：目标真实位置；
* \(\mathcal{E}\)：环境/地形几何；
* \(c_t\)：其他影响可见性的状态。

注意：

$$
\boxed{x^T,\mathcal E\notin\text{deployment observation}}
$$

它们存在于环境中，但机器人不知道。

# 2.2 相机观测

机器人真正获得：

$$
o_t =
(I_t,D_t,q_t)
$$

其中：

* \(I_t\)：RGB；
* \(D_t\)：Depth；
* \(q_t\)：机器人可获得的自身状态，例如 IMU/odometry。

如果你的实验最终只允许 RGB：

$$

$$

如果允许 RGB-D：

$$
o_t=(I_t,D_t)
$$

# 2.3 历史信息

机器人并不是单帧决策，而是：

$$
h_t=
\left\{

a_{0:t-1}
\right\}

必要时加入估计运动：

$$
h_t=
\left\{
I_{0:t},
D_{0:t},
a_{0:t-1},
\Delta\hat{x}_{0:t}
\right\}
$$

这非常重要。

因为你的 H1 已经说明：

$$

$$

但是：

$$
a_A^*\neq a_B^*
$$

因此：

$$
\boxed{
\pi(a_t|o_t)
}
$$

一般是不充分的。

需要：

$$
\boxed{
\pi(a_t|h_t)
}
$$

# 三、你的“目标记忆”也不能是 GT 坐标

例如：

* target crop；
* target embedding；
* target appearance；

* target bounding box；
* target segmentation mask。

但是不能保存：

更不能直接保存：

```text

```

否则问题就从：

> visual target reacquisition

变成：

> target localization + action planning。

这是两个问题。

# 四、目标丢失后的正式问题

定义目标可见性：

$$
V_t =
\begin{cases}
1,&T\text{ is visible in camera at }t\\
0,&\text{otherwise}
\end{cases}
$$

目标丢失时：

$$
V_t=0
$$

Agent 要选择：

$$
a_t\in\mathcal A
$$

使：

$$
V_{t+1}=1
$$

或者更一般：

$$
\exists k\le K,\quad V_{t+k}=1
$$

因此你的核心目标可以写成：

$$
\boxed{
a_{t:t+K-1}^*
=
\arg\max_{a_{t:t+K-1}}
P
\left(
\exists k\le K:
V_{t+k}=1
\mid
h_t,m_T
\right)
}
$$

这就是你的真正数学问题。

# 五、这其实是 POMDP

可以严格定义：

$$
\mathcal M=
(\mathcal S,\mathcal A,\mathcal O,T,Z,R,\gamma)
$$

其中：

### State

$$
s_t=(x_t^R,x^T,\mathcal E)
$$

### Action

例如：

$$
a_t=
(\Delta x,\Delta y,\Delta\theta)
$$

或者你的实际移动 primitive：

$$
\mathcal A=
\{
\text{forward},
\text{backward},
\text{left},
\text{right},
\text{turn-left},
\text{turn-right}
\}
$$

### Observation

$$
o_t=(I_t,D_t,\hat q_t)
$$

### Transition

$$
s_{t+1}
\sim
T(s_{t+1}|s_t,a_t)
$$

### Observation model

$$
o_{t+1}
\sim
Z(o_{t+1}|s_{t+1})
$$

### Reward

最简单：

$$
R_t=
\begin{cases}
1,&V_t=1\\
0,&V_t=0
\end{cases}
$$

但我建议最终不要只用这个。

可以定义：

$$
R=
\lambda_VV
-\lambda_CC_{\text{action}}
-\lambda_FF_{\text{failure}}
$$

于是你最终不是：

> “走到目标位置”。

而是：

> **通过行动改变 camera viewpoint，使 previously observed target become observable again。**

# 六、这与 NBV 有什么区别？

这是论文 Related Work 必须处理的。

传统 active vision / NBV 的核心是：

$$
a^*=
\arg\max_a
\text{InformationGain}(a)
$$

即：

> 哪个 viewpoint 能提供最多新信息？

经典 view planning / NBV 研究的确把 viewpoint selection 作为主动视觉问题。([SciOpen][2])

甚至 2026 年非常新的 OA-NBV 已经明确研究：

> 遮挡目标 → 选择下一个可行 viewpoint → 获得更完整目标观察。

而且它已经开始考虑 occlusion-aware viewpoint planning 和真实运动约束。([arXiv Science][3])

所以你**绝对不能**写：

> “以前没有人研究目标遮挡后的重新观察。”

这个 claim 很危险。

你的差异应该更加精确：

### NBV：

$$
\text{current scene}
\rightarrow
\text{best viewpoint}
$$

### 你的问题：

$$
\text{target previously observed}
\rightarrow
\text{target lost}
\rightarrow
\text{action}
\rightarrow
\text{physical viewpoint change}
\rightarrow
\text{target reacquisition}
$$

尤其你关注：

$$
\boxed{
\text{terrain-induced occlusion}
+
\text{embodied action}
+
\text{visual history}
+
\text{closed-loop recovery}
}
$$

而不是单纯求一个静态 NBV。
